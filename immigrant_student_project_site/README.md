# Rooted & Rising — Website

This is a plain HTML/CSS/JavaScript website, so you can edit it without needing a special website builder.

## How to view it
Open `index.html` in a browser.

## What to edit
- Page text: edit the `.html` files.
- Colors, spacing, fonts, layout: edit `style.css`.
- Mobile navigation: edit `script.js`.
- Replace `YOUR-EMAIL-HERE` in `get-involved.html` with the project email you want visitors to use.

## Pages
- index.html — Home
- mission.html — Our Mission
- resources.html — Resources
- stories.html — Stories
- get-involved.html — Get Involved

## Important
The resources page intentionally uses placeholder content. Before publishing, replace placeholders with carefully checked, age-appropriate educational resources and appropriate support information.

## Putting it online
You can later upload these files to a free static-hosting service such as GitHub Pages, Netlify, or Cloudflare Pages.
